Agent

大模型 + 工具，自己转圈直到干完

一个读过全世界书的脑子，配上一双能动手的手脚，再给一个目标：它会自己计划、动手、看结果、不对就改。

大模型

通用知识，能读会写会推理。它知道“全世界的平均”，不知道“你们公司的具体”。

工具

查网页、读文件、算表格、操作软件。这是它的手和眼，决定它能干多远。

合起来 = Agent

给它目标，它自己转圈：计划 → 动手 → 看结果 → 不对就改，直到交付。

实战 · 第 1 / 10 步同一个项目 · 竞品情报周报

把「查 5 家 + 比价格 + 找活动 + 写成周报」整件事交出去，中途别插手。

→ 拿到一份它自己跑完的周报；抓不到的地方，标了「待人工核对」。

第 3 步报错了。没人提醒，他自己换了办法。

你设定目标，Agent 用大模型和工具为你实现。
